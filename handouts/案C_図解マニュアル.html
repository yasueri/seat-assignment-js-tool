座席配置ツール 図解マニュアル

CSVを準備して自動配置を実行する担当者向け。印刷してもそのまま使えます（ブラウザの印刷機能でA4）。

1. 3分でわかる使い方

1CSVを読み込む画面上部の枠へまとめてドラッグ＆ドロップ。ファイル名の shift / ojt / rookie / secret で自動振り分け
2日付を選ぶ「配置対象日」でその日の出勤者を抽出
3自動配置を実行ボタンを押すだけ
4メッセージ確認「2. メッセージ」欄の警告を必ず読む（エラーでも配置は止まらない）
5手動調整必要ならカードをドラッグで微調整（✎で氏名・時刻の編集も可）
6配置違反チェック手動調整した場合は「手動変更後 配置違反チェック」で確認
7印刷する日付確認画面でOK →そのまま印刷プレビューまで進む

必須は月間シフトCSVのみ。ojt.csv / rookie.csv / secret.csv は任意で、読み込んだものに対応するルールだけが使われます。印刷までが一連の基本作業です。

2. 座席マップと「列」「隣接」の意味

3. CSVファイル早見表

ファイル必須役割列
月間シフトCSV必須その月の全出勤情報日付, 氏名, 開始時刻, 終了時刻, 前残業, 後残業, 役割
rookie.csv任意新人の固定席（席5〜8）氏名, 新人度合い
secret.csv任意禁止席・固定席・要サポート・隣接禁止・優先フラグ種別, 対象1, 対象2, 対象座席, 優先フラグ
ojt.csv任意教官とOJT対象者の同席教官名, OJT一人目, OJT二人目, 対象座席

4ファイル共通のルール

項目ルール
文字コードUTF-8（BOM付き可）。Excelでは「CSV UTF-8」形式で保存
1行目ヘッダー行として残す（ずれると警告。処理は列の位置で続行）
氏名月間シフトCSVと同じ表記にそろえる（姓名の間のスペースの有無・全角半角まで一致。前後の空白のみ無視）
座席番号半角数字（1〜15）。複数はスペース区切り（半角・全角どちらも可）、入力順＝優先順

4. ファイル別の書きかた

月間シフトCSV 必須｜例: 2026-06_shift.csv
日付氏名開始時刻終了時刻前残業後残業役割
2026-06-01山田太郎7:3016:30FALSEFALSE役席
2026-06-01後藤四郎11:0022:00TRUEFALSEOP
2026-06-01佐藤花子22:0032:00FALSEFALSEGL
列ルール
日付YYYY-MM-DD または YYYY/M/D（2026-06-01 / 2026/6/1 どちらも可）
氏名同じ日付・氏名の重複行は不可（最初の行のみ使用）
時刻HH:MM。日をまたぐ夜勤の終了は24時以降の延長表記（例: 32:00 = 翌8:00）
前残業/後残業TRUE / FALSE（空欄はFALSE扱い）。TRUEの時刻はカード上で黄色＋※表示
役割役席 / GL / OP のいずれか
よくある間違い
× 夜勤明けの終了時刻を 8:00 と書く → ○ 32:00 と書く
× Excelで普通の「CSV」保存（文字化けの原因）→ ○ 「CSV UTF-8」で保存

夜勤の判定: 開始が22:00より遅い、または終了が26:00より遅い人。役席・GLの遅番判定: 開始12:00以降、または前残業TRUEかつ開始10:00以降。

rookie.csv 任意｜新人リスト
氏名新人度合い
山田太郎1
田中次子2

数値が小さいほど新人として優先。同数値なら、その日の月間シフトCSVで後ろの行の人がより新人扱い。対象はOPのみ。

secret.csv 任意｜禁止席・固定席・要サポート・隣接禁止・優先フラグ
種別対象1対象2対象座席優先フラグ
隣接禁止山田太郎佐藤花子
禁止席鈴木一郎5
固定席高橋次郎7 11
固定席近藤　美穂夜勤GL席
要サポート中村五郎2 6
禁止席渡辺六郎11
種別意味書きかた
隣接禁止対象1と対象2を同じ列の隣の席にしない対象2に相手の氏名。同じ人を複数行に書いてもよい
禁止席対象座席には配置しない対象2は空欄。対象座席は半角数字をスペース区切りで（例 7 11 → 7を優先、空いていなければ11）。1人1行にまとめる（同じ人・同じ種別が2行以上あると自動配置が実行できない）
固定席対象座席に必ず配置する
要サポート独り立ち前のスタッフ（要サポバッジ）。ルールは固定席と同じ

「夜勤GL席」（固定席のみ指定可）… 夜勤の役席・GLが2名以上いる日に夜勤GL枠へ優先して入れたい人。夜勤GL席 3 と書くと「夜勤GL枠か3番のどちらか」。複数人が指定していれば当日の該当者からランダムに1名を選出し、選ばれなかった人は座席1〜15に配置され「夜勤GL席」バッジが付きます。日勤には影響しません。

優先フラグ … どの種別の行にも書け、対象1に適用。数値が小さい人ほど全ルール中の最優先で配置（複数行なら最小値を採用。半角・全角どちらの数字も可）。

よくある間違い
× 同じ人の禁止席を2行に分ける → ○ 1行に 5 9 のようにまとめる（隣接禁止だけは複数行OK）
× 対象座席を全角数字 ７ で書く → ○ 半角 7（区切りスペースは全角可・優先フラグの数字は全角可、という違いに注意）
× 禁止席・要サポートに「夜勤GL席」→ ○ 「夜勤GL席」は固定席のみ
ojt.csv 任意｜教官・OJTの組み合わせ
教官名OJT一人目OJT二人目対象座席
教官　朝三新人　一
教官　朝八新人　二新人　三12
項目ルール
行のつくり教官1名につき1行（同じ教官が複数行にまたがるとエラー）。OJT一人目は必須、二人目は空欄可
教官1名+OJT1名
のデフォルト席		対象座席を指定しない場合、15番→12番→8番→4番→他の順に空席を探し、最初に見つかった座席へ2人まとめて同席（この組み合わせに限り勤務時間が重なっても可）
教官1名+OJT2名
のデフォルト席		対象座席を指定しない場合、(教官+一人目,二人目) の組を
(15,14)→(12,8)→(12,11)→(8,7)→(4,3)→(11,7)→(11,10)→(7,6)→(3,2)→(14,13)→(10,6)→(6,5)→(2,1)
の順で試し、両方空いていた最初の組を採用（座席9番はどの組にも現れないため、13通りすべて埋まっていれば3名を個別に通常の空席探索で配置する）
混在時
のデフォルト席		OJT2名側を上記の順で先に確定 → OJT1名側は既定順（15→12→8→4→他）で空きがなければ、OJT2名側が使った座席の「同列1つ前」を追加候補に（例: 12&8番なら11番・7番）
担当教官が不在担当人数に空きのある他教官へ自動振替。振替先がなければOJT対象者のみで配置しメッセージ表示 → 臨時の教官役を手動で同じ席へドラッグ（違反チェックでは確認メッセージのみ）
補足教官が役席・GLでも担当OJTが出勤する日は座席グリッド側へ。OJT対象者が新人上位4名を兼ねる場合は新人固定席が優先され同席しない

5. 自動配置の順番（優先順位）

座席1〜15より先に確定する別枠
・日勤の役席・GL → 早番/遅番エリア（役席→GLの順・出勤時刻順、合計6名まで。7人目以降は「あふれ」に入る）
・夜勤の役席・GL → 夜勤GL枠に1名（「夜勤GL席」指定者を優先。複数/不在ならランダム）、2人目は座席10へ、3人目以降は通常配置に合流
  1. 0. 優先フラグsecret.csv
    全ルール中の最優先。数値が小さい人から。同数値は「新人→固定席→教官・OJT→要サポート→その他」→出勤時刻順
  2. 1. 新人固定席rookie.csv
    席5→6→7→8へ上から詰める（上位4名・OPのみ）
  3. 2. 固定席secret.csv
    候補座席が少ない人を先に（同数なら出勤時刻順）。候補の入力順＝優先順
  4. 3. 教官・OJTojt.csv
    教官+OJT一人目を同席、二人目は近くの席をペアで確保
  5. 4. 要サポートsecret.csv
    並び順ルールは固定席と同じ
  6. 5. 隣接禁止・禁止席の対象者（未配置の人）secret.csv
    枝刈り付き全探索（backtrack）で「全員置ける組み合わせ」をすべて探し、偏りが少なく・勤務時間がぴったり接する同席が少ない案を自動採用。「本当は解けるのにあふれる」ことを防ぐ。1件も見つからない/制限時間（既定2秒）超過の時のみ出勤時刻順にフォールバック
  7. 6. その他スタッフ
    出勤時刻が早い順に空席へ

各段階で配置済みの人は後の段階では処理されません。指定席に置けなかった場合はメッセージを出して通常の空席探索へ。夜勤のみ、同列で隣接する座席を（他に候補がある限り）避けます。固定席などの都合で隣接するのは問題ありません。

6. 画面の見かた（バッジ）

表示意味
新人1〜新人4rookie.csv記載者の新人固定席での優先順位
固定席secret.csvで座席指定。候補1〜2件は座席番号、3件以上は「複数有」と表示
要サポ要サポート対象者。表示ルールは固定席と同じ
禁止席禁止席の対象者。表示ルールは固定席と同じ
隣禁止ペア（secret.csvの行）ごとにA・B・C…。自分が属するペアの記号をすべて表示（例: 2ペアなら「AB」、4ペア以上は「4以上」）。同じ記号の人同士が相手
夜勤GL席「夜勤GL席」指定だが枠に選ばれず座席1〜15に配置された人（夜勤のみ）
教官 / OJTojt.csv記載者
7:30※時刻が黄色＋※ … その時刻は残業（前残業/後残業）

配置しきれなかった人は右の「あふれ」欄へ（早番・遅番エリアの6名超過分も同じ「あふれ」欄に入ります）。夜勤パネル左の見出しのない枠は予備枠で、一時置き場や印刷後の手書きスペースに使えます。座席9番は通常の自動配置では対象外ですが、固定席・要サポート・教官/OJT同席で明示指定されていれば配置されます（手動でのドラッグ配置は常に可能）。

7. ボタンと注意点

ボタン動作
次の案backtrackで見つかった別案（最大20件）へ切替。secret.csv対象者以外の座席は変わらない。実行可能な案が1通りだけの日は押せない
その他の座席をシャッフルsecret.csv対象者はそのまま、その他スタッフの座席だけランダムに振り直し
手動変更後 配置違反チェックドラッグ操作はルールを自動チェックしないため、手動調整後に実行。座席ルールに加え、日勤・夜勤の入れ違いや夜勤GL枠の空きも検出。教官・OJT本人同士の時間重複同席は違反にならず、OJT+臨時教官は確認メッセージのみ
印刷する座席表の日付を確認する画面が出る（OKでそのまま印刷プレビューまで進む。1ページ目=日勤、2ページ目=夜勤のA4各1枚・両面コピー用）
現在の配置を保存 / 読み込む表示中の配置（手動調整含む）をJSONでダウンロード / 復元
「次の案」「シャッフル」は、押した時点までの手動調整を上書きします。ボタンを押した後でも手動調整は通常どおり行えますが、押すたびにそれまでの調整が失われるため、案を決めてから手動で微調整するのがおすすめです（座席が変わった人のカードは一瞬光ります）。
保存ファイルに secret.csv・ojt.csv 由来の情報は含まれません（固定席・禁止席・教官/OJTなどのバッジ情報を含む）。読み込み後にバッジ表示や違反チェックを使うには、両CSVを読み込み直してください（同じセッションで読み込み済みなら自動適用）。

8. 困ったときは

まず「2. メッセージ」欄を読んでください。入力エラーがあっても自動配置は止まらず、行番号つきの警告として表示されます。配置結果に反映されない行がないか、実行のたびに確認する習慣がいちばんの近道です。

細かい判定ルールの要約は、画面内の折りたたみ説明（▼）にもあります。
