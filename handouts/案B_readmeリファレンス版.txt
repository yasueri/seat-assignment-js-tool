1. 概要・ファイル構成
----------------------------------------------------------------
月間シフトCSVを読み込み、指定した日の座席配置を自動計算する
ブラウザ完結型ツールです。rookie.csv・secret.csv・ojt.csv を
読み込ませると、該当するルールを使って自動配置します。
サーバー・インターネット接続は不要で、index.html を開くだけで動作します。

  任意のフォルダ/
  ├─ index.html        … 本体（ブラウザで開くファイル）
  ├─ css/style.css     … 画面デザイン
  ├─ js/csv.js         … CSVの読み込み・解析・入力チェック
  ├─ js/algorithm.js   … 自動配置ロジック（貪欲+MRV、secret.csv対象者の
  │                       枝刈り付き全探索backtrackを含む）
  ├─ js/ui.js          … 画面表示・D&D・手動編集・違反チェック・印刷・保存/読込
  └─ readme.txt        … このファイル

2. 基本の使い方
----------------------------------------------------------------
  [1] CSV読込 → [2] 日付選択 → [3] 自動配置 → [4] メッセージ確認 →
  [5] 手動調整 → [6] 配置違反チェック → [7] 印刷する
  （印刷までが一連の基本作業です）

  1. 画面上部の枠に、月間シフトCSV（必須）と ojt.csv / rookie.csv /
     secret.csv（任意）をまとめてドラッグ＆ドロップするか、各ボタンから
     個別に選択します。
     ※ファイル名に "shift" "ojt" "rookie" "secret" のいずれかを含めると
       自動で振り分けられます。
  2. 「配置対象日」で配置したい日を選びます（年月はCSVから自動表示）。
  3. 「自動配置を実行」を押します。
  4. 「2. メッセージ」欄の警告を確認します。入力エラーがあっても配置は
     止まらず警告として表示されるため、反映されなかった行がないか
     実行後に必ず確認してください。
  5. 必要であれば、座席カードをドラッグ＆ドロップして手動調整します
     （✎アイコンで氏名・時刻の編集や削除も可能）。
  6. 手動調整をした場合は「手動変更後 配置違反チェック」を押して
     確認します（ドラッグ操作はルールを自動チェックしないため）。
  7. 「印刷する」を押します。日付確認画面でOKを押すと、追加のクリック
     なしにそのまま印刷プレビューまで進みます。

3. 座席マップと用語
----------------------------------------------------------------
  座席は全15席。右下の1席は存在しません。

        列1   列2   列3   列4
       ┌────┬────┬────┬────┐
       │  1 │  5 │  9 │ 13 │
       │  2 │  6 │ 10 │ 14 │
       │  3 │  7 │ 11 │ 15 │
       │  4 │  8 │ 12 │ ―  │
       └────┴────┴────┴────┘

  覚えておく座席:
    5〜8      … 新人固定席（rookie.csv使用時、上から順に新人1〜4）
    9         … 自動配置では使用しません（禁止席・固定席・教官/OJT同席・
                 新人固定席・通常探索・全探索を含む、すべての自動処理で
                 除外。手動でのドラッグ＆ドロップでは配置可能）
    10        … 夜勤の役席・GLが2名以上いる日の2人目が入る席
    15/12/8/4 … 教官・OJT同席の既定の探索順（15→12→8→4→他）

  用語:
    「列」       … 上の図の縦方向のまとまり（列2＝座席5〜8）
    「隣接」     … 同じ列で上下にとなり合うこと（例: 5と6）。
                    隣接禁止・夜勤の隣接回避はこの意味で判定します
    「日勤/夜勤」… 夜勤＝開始時刻が22:00より遅い、または終了時刻が
                    26:00より遅いスタッフ。それ以外は日勤
    「早番/遅番」… 役席・GL用。遅番＝開始12:00以降、または
                    前残業TRUEかつ開始10:00以降。それ以外は早番

4. CSV仕様
----------------------------------------------------------------
◆ 4ファイル共通ルール
  ・1行目はヘッダー行。UTF-8（BOM付き可）。Excelでは「CSV UTF-8」で保存。
  ・文字コードや列の位置がずれるとヘッダーチェックで警告が出ますが、
    処理自体は列の位置で続行します。
  ・氏名は月間シフトCSVと同じ表記にそろえます（前後の空白は無視されますが、
    姓名の間のスペースの有無・全角半角は区別されます）。
  ・座席番号は半角数字（1〜15）。複数指定は半角・全角スペース区切りで、
    入力した順が優先順位になります。
  ・座席9番は通常の自動配置（新人固定席・その他スタッフの通常探索など、
    明示指定によらない候補選び）では使いません。ただし secret.csv の
    固定席・要サポート、ojt.csv の対象座席で座席9番を明示的に指定した
    場合は例外的に配置され、その旨のメッセージが出ます（詳細は5章）。

◆ (1) 月間シフトCSV（例: 2026-06_shift.csv）※必須
  列: 日付, 氏名, 開始時刻, 終了時刻, 前残業, 後残業, 役割

   列       | 形式・値                        | 例
  ----------+---------------------------------+---------------
   日付     | YYYY-MM-DD または YYYY/M/D      | 2026-06-01
   氏名     | 同じ日付・氏名の重複行は不可    | 山田太郎
            | （最初の行のみ使用）            |
   開始時刻 | HH:MM                           | 22:00
   終了時刻 | HH:MM。日をまたぐ夜勤は24時以降 | 32:00（=翌8:00）
            | の延長表記                      |
   前残業   | TRUE / FALSE（空欄はFALSE扱い） | TRUE
   後残業   | 同上                            | FALSE
   役割     | 役席 / GL / OP のいずれか       | OP

  1か月分をまとめて入力し、ツール側で日付ごとに抽出します。

◆ (2) rookie.csv（新人リスト）※任意
  列: 氏名, 新人度合い
  ・新人度合いは数値。小さいほど新人として優先扱い。
    同数値の場合は、月間シフトCSV内でその日の後ろの行にある人が
    より新人として扱われます。
  ・対象はOPのみ。新人度合いが小さい人から順に、列2の座席5→6→7→8へ
    上から詰めて配置します（最大4名。5人目以降は新人固定席を使わず
    通常どおり配置）。
  ・未読み込みの場合、新人固定席ルールを使わずに配置します。

◆ (3) secret.csv（禁止席・固定席・要サポート・隣接禁止・優先フラグ）※任意
  列: 種別, 対象1, 対象2, 対象座席, 優先フラグ

   種別     | 意味                            | 対象2 | 対象座席
  ----------+---------------------------------+-------+------------------
   禁止席   | 対象1をその座席に置かない       | 空欄  | 座席番号
   固定席   | 対象1をその座席に必ず置く       | 空欄  | 座席番号 or 夜勤GL席
   要サポート| 独り立ち前のスタッフ。入力形式・| 空欄  | 座席番号
            | 優先順位ルールは固定席と同じ。  |       |
            | 画面に「要サポ」バッジ          |       |
   隣接禁止 | 対象1と対象2を同じ列の隣接座席に| 相手  | 空欄
            | 置かない                        | の氏名|

  ・対象座席の複数指定は入力順が優先順位（例: "7 11" → 7を優先、
    空いていなければ11）。
  ・禁止席・固定席・要サポートは1人1行にまとめます。同じ人が同じ種別で
    2行以上に分かれていると重複として検出され、自動配置を実行できません。
    隣接禁止のみ、同じ人について複数行書けます。
  ・「夜勤GL席」（固定席のみ指定可）… 夜勤の役席・GLが2名以上いる日に、
    夜勤GL枠へ優先的に入れたい人の指定。数字と組み合わせて
    「夜勤GL席 3」（夜勤GL枠か3番のどちらか）とも書けます。
    複数人が指定している場合は当日の該当者からランダムに1名を選び、
    選ばれなかった人は座席1〜15に配置のうえ「夜勤GL席」バッジが付きます。
    日勤の配置には影響しません。
  ・優先フラグ … 種別を問わずどの行にも指定可。対象1の氏名に適用され、
    値が小さいほど全ルールの中で最優先に配置されます（複数行で異なる
    値があれば最小値を採用）。数字は半角・全角どちらも可。

◆ (4) ojt.csv（教官・OJTの組み合わせ）※任意
  列: 教官名, OJT一人目, OJT二人目, 対象座席
  ・教官1名につき1行（同じ教官が複数行にまたがるとエラー）。
  ・OJT一人目は必須。OJT二人目は空欄可（担当が1名のみの日）。
  ・対象座席は「教官とOJT一人目が同席する座席」の優先順。空欄なら
    既定順（15→12→8→4→他）。"12"→12→15→8→4→他、
    "12 4"→12→4→15→8→他。OJT二人目がいる場合のペア席の探索順は
    ここから自動計算されるため、ペアの座席番号を別途指定する必要は
    ありません。座席9番は既定順・「他」のどちらにも現れませんが、
    対象座席に明示的に "9" と書いた場合は候補に加わり、配置されると
    メッセージでその旨を知らせます（教官1名・OJT2名のペア配置では、
    対象座席の指定は12↔15の優先順にのみ影響し、座席9番を候補に
    加える効果はありません＝詳細は次項）。

  配置のされ方（担当人数別・具体的な座席番号）:
  ・教官1名・OJT1名のデフォルト席 … 対象座席を指定しない場合、
    15番から順に、空いていなければ12番→8番→4番、それでも空きがなければ
    他の空いている座席、の順に探し、最初に見つかった座席へ2人まとめて
    座らせます（この組み合わせに限り勤務時間が重なっていても同席可）。
    対象座席に "9" を明示指定した場合はその順番どおり座席9番も候補に
    含まれます。
  ・教官1名・OJT2名のデフォルト席 … 対象座席を指定しない場合、
    (教官+OJT一人目, OJT二人目) の組み合わせを次の順で試します:
      (15,14) → (12,8) → (12,11) → (8,7) → (4,3) → (11,7) → (11,10)
      → (7,6) → (3,2) → (14,13) → (10,6) → (6,5) → (2,1)
    最初に両方とも空いていた組み合わせを採用します。教官側は時間重複を
    許可した同席判定、OJT二人目側は通常どおり時間が重ならないことが
    条件です。座席9番はこの13通りのどの組み合わせにも現れないため、
    すべて埋まっていれば3名を個別に通常の空席探索で配置します（この
    組み合わせリストに将来座席9番を含む組を追加した場合は、そのまま
    候補として使われるようになっています）。
  ・混在時（教官1名・OJT2名と教官1名・OJT1名が同じ日にある場合）の
    デフォルト席 … 2名側を上記の順で先に配置し、使った座席番号を
    記録します。1名側は既定順（15→12→8→4→他）で空きがなければ、
    記録した座席の「同列で1つ前」を追加候補として試します（例:
    2名側が既定どおり15・14番になった場合、追加候補は14番の1つ前＝
    13番。2名側が12・8番になった場合は11・7番が追加候補）。この
    「1つ前」の候補は自動算出されたものであり明示指定ではないため、
    仮に座席9番が算出結果に含まれても対象外のままです。
    これにより教官同士が近くに集まりやすくなります。
  ・担当教官が不在の日 … 担当人数に空きのある他の教官へ自動で振り分けます
    （座席の優先順は振り分け先の教官の対象座席を使用）。振り分け先が
    なければOJT対象者のみで配置し、メッセージで知らせます。その場合は
    臨時の教官役を手動で同じ座席へドラッグしてください（時間重複の同席は
    違反ではなく確認メッセージのみ表示されます）。
  ・教官の役割が役席・GLでも、担当OJT対象者が出勤している日は早番・遅番
    エリアではなく座席グリッド側に配置されます。
  ・OJT対象者が新人（rookie.csv上位4名）を兼ねる場合、新人固定席が
    優先されるため教官とは同席しません。

5. 自動配置の順番（優先順位）
----------------------------------------------------------------
  ┌─ 別枠（座席1〜15より先に確定）───────────────┐
  │ 日勤の役席・GL → 早番/遅番エリア（役席→GLの順・出勤時刻順、  │
  │                  1枠1名・合計6名まで。7人目以降は「あふれ」に │
  │                  入ります）                                   │
  │ 夜勤の役席・GL → 夜勤GL枠に1名（「夜勤GL席」指定者を優先。    │
  │                  該当者が複数/不在ならランダム）、2人目は     │
  │                  座席10へ強制配置、3人目以降は通常配置に合流  │
  └───────────────────────────────┘
                          ↓
  座席1〜15（上の段階で配置済みの人は以降の対象から除外。
  座席9番は通常この探索の対象外ですが、固定席・要サポート・教官/OJT
  同席で明示指定されていれば例外的に使われます）
   0. 優先フラグ（secret.csv）
        全ルール中の最優先。数値が小さい人から。同数値は
        「新人→固定席→教官・OJT→要サポート→その他」→出勤時刻が早い順
        （同時刻ならCSVで後ろの行を先に）。固定席/要サポートの指定が
        あればその候補座席（入力順）、なければ通常の空席探索。
   1. 新人固定席（rookie.csv）… 席5→6→7→8。指定枠に座れなかった場合は
        優先的に通常探索へ回します。
   2. 固定席（secret.csv）… 候補座席が少ない人を先に（同数なら出勤時刻順）。
   3. 教官・OJT（ojt.csv）
   4. 要サポート（secret.csv）… 並び順ルールは固定席と同じ。
   5. secret.csv記載スタッフ（隣接禁止・禁止席の対象者で未配置の人）
        貪欲な当てはめではなく、枝刈り付き全探索（backtrack）で
        「全員を配置できる組み合わせ」をすべて探します。「今置ける座席が
        一番少ない人」から順に試し、行き詰まったら別の組み合わせへ。
        これにより「本当は解けるのに、たまたま見つからずあふれる」ことを
        防ぎます。見つかった案のうち、座席の偏りが少なく、勤務時間が
        ぴったり接する同席が少ないものを自動採用します。
        1件も見つからない（条件が矛盾等）か制限時間（既定2秒）を超えた
        場合のみ、出勤時刻順の当てはめにフォールバックします。
   6. その他スタッフ … 出勤時刻が早い順に空席へ。

  ※夜勤に限り、座席探索の際は同列で隣接する座席を（他に選べる候補が
    ある限り）避けます。固定席などの都合で隣接するのは問題ありません。

----------------------------------------------------------------
6. 画面の見かた
----------------------------------------------------------------
  バッジ:
   新人1〜4  … rookie.csv記載者の新人固定席での優先順位
   固定席    … secret.csvで座席指定。候補1〜2件は番号、3件以上は「複数有」
   要サポ    … 要サポート対象者。表示ルールは固定席と同じ
   禁止席    … 禁止席の対象者。表示ルールは固定席と同じ
   隣禁止    … 隣接禁止の対象者。ペアごとにA・B・C…が付き、自分が属する
               ペアの記号をすべて表示（4ペア以上は「4以上」）。同じ記号を
               持つ人同士が隣接禁止の相手
   夜勤GL席  … 「夜勤GL席」指定だが枠に選ばれず座席1〜15に配置された人
   教官/OJT  … ojt.csv記載者

  ・出退勤時刻が黄色マーカー＋※ … その時刻が残業（前残業/後残業）
  ・あふれ欄 … 配置しきれなかったスタッフ。早番・遅番エリアの6名超過分も
    同じ「あふれ」欄に入ります
  ・夜勤パネル左の見出しのない枠は予備枠。自動配置では使わず、カードの
    一時置き場や印刷後の手書きスペースに使えます

----------------------------------------------------------------
7. 操作
----------------------------------------------------------------
  ドラッグ＆ドロップ … 人単位の入れ替え。早番⇔遅番、座席⇔あふれなど
                        枠をまたいだ移動も自由
  ✎アイコン           … 氏名・時刻の手入力修正、その日の配置からの削除
  手動変更後 配置違反チェック
      … ドラッグ操作はルールを自動チェックしないため、手動調整後に実行。
        座席ルール違反に加え、日勤・夜勤の入れ違いや、夜勤の役席・GLが
        いるのに夜勤GL枠が空のケースも検出。時間重複の同席はエラーですが、
        ojt.csvの教官・OJT本人同士は対象外。OJT対象者と臨時教官の同席は
        エラーではなく確認メッセージになります
  次の案               … backtrackで見つかった別案（最大20件）に切替。
                        secret.csv対象者以外の座席は変わりません。
                        実行可能な案が1通りだけの場合は押せません
  その他の座席をシャッフル
      … secret.csv対象者の配置はそのままに、その他スタッフの座席だけを
        ランダムに振り直し
      ※「次の案」「シャッフル」とも、押した時点までの手動調整の内容を
        上書きします。ボタンを押した後でも手動調整（ドラッグ＆ドロップ・
        ✎編集）は通常どおり行えますが、そのつど押す前の調整が失われる
        ため、案を決めてから手動微調整するのがおすすめです。変わった人の
        カードは一瞬光ります
  印刷する             … 座席表の日付を確認する画面が出ます（違っていれば
                        その場で修正可）。OKを押すと1ページ目=日勤、
                        2ページ目=夜勤のA4各1枚の印刷用ページが開き、
                        追加のクリックなしにそのままブラウザの印刷
                        プレビューまで進みます（両面コピー用）。プレビュー
                        を誤って閉じた場合は、開いたページ上部の
                        「この内容を印刷する」ボタンで手動に印刷できます
  現在の配置を保存 / 保存した配置を読み込む
      … 表示中の配置（手動調整含む）をJSONでダウンロード/復元。
        保存ファイルには secret.csv・ojt.csv 由来の情報（固定席・禁止席・
        教官/OJT等のバッジ情報）は含まれません。読込後にバッジ表示や
        違反チェックを使うには両CSVの再読み込みが必要です（同じセッション
        で読み込み済みなら自動適用）

----------------------------------------------------------------
8. よくある間違い チェックリスト
----------------------------------------------------------------
  □ Excelで普通の「CSV」で保存した
      → 「CSV UTF-8」形式で保存し直す（文字化け・ヘッダー警告の原因）
  □ 夜勤の終了時刻を「8:00」と書いた
      → 翌朝は「32:00」のように24時以降表記で書く
  □ 同じ日付・同じ氏名の行が2行ある
      → 最初の行しか使われない。1行にまとめる
  □ rookie.csv / secret.csv / ojt.csv の氏名がシフトCSVと微妙に違う
      → 姓名の間のスペースの有無・全角半角までそろえる
  □ secret.csvで同じ人の禁止席（または固定席・要サポート）を2行に分けた
      → 自動配置が実行できない。1行にまとめ座席をスペース区切りで
        （隣接禁止だけは複数行OK）
  □ 対象座席を全角数字で書いた
      → 座席番号は半角のみ（「認識できません」警告になる）。
        区切りスペースは全角でも可。優先フラグの数字は全角でも可という
        非対称に注意
  □ 禁止席・要サポートに「夜勤GL席」を書いた
      → 「夜勤GL席」は固定席のみ指定可
  □ ojt.csvで同じ教官を2行に書いた → エラー。1行にまとめる
  □ ojt.csvの対象座席に "9" と書けば、教官1名・OJT2名のペア配置でも
    座席9番を使えると思っていた
      → ペア配置の候補座席一覧（13通り）は、対象座席の指定に関わらず
        システム既定の組み合わせで、現時点では座席9番を含む組がない
        ため使われない。座席9番が使えるのは、本人の候補として直接
        使われる場合（固定席・要サポート・教官1名+OJT1名の同席）のみ
  □ 実行後にメッセージ欄を見ていない
      → 警告があっても配置は止まらないため、必ず確認する

9. 注意事項
----------------------------------------------------------------
  ・本ツールはオフライン動作前提のため、外部ライブラリやサーバーへの
    通信は行いません。
  ・入力エラーがあっても自動配置自体は止まらず、メッセージ欄に警告として
    表示されます。配置結果に反映されない行がないか、実行後に確認して
    ください。
  ・画面内の折りたたみ説明（▼）にも、各項目の判定ルールの要約があります。
