========================================
座席配置ツール クイックガイド（1枚版）
========================================
月間シフトCSVを読み込み、選んだ日の座席配置を自動計算するツールです。
サーバー・ネット接続は不要。index.html をブラウザで開くだけで動きます。

■ 使い方（6ステップ・印刷までが一連の作業です）
  1. 画面上部の枠にCSVをまとめてドラッグ＆ドロップ
       必須: 月間シフトCSV（ファイル名に shift を含める）
       任意: ojt.csv / rookie.csv / secret.csv
       ※ファイル名の shift / ojt / rookie / secret で自動振り分け
  2. 「配置対象日」で日を選ぶ
  3. 「自動配置を実行」を押す
  4. 「2. メッセージ」欄の警告を確認する（反映されなかった行がないか）
  5. 気になる席はカードをドラッグ＆ドロップで微調整
       → 動かしたら必ず「手動変更後 配置違反チェック」を押す
  6. 「印刷する」を押す
       → 日付確認画面でOKを押すと、そのまま印刷プレビューまで進みます

■ よく使うボタン
  次の案                   … 配慮対象者（secret.csv）の座席だけ別案に切替
  その他の座席をシャッフル … 配慮対象者以外の座席だけランダムに振り直し
      ※どちらのボタンも、押した時点までの手動調整を上書きします。押した
        あとでも手動調整はできますが、そのつど調整前の状態に戻るため、
        案を決めてから微調整するのがおすすめです。
  印刷する                 … 日付確認→そのまま印刷プレビューまで進みます
                              （A4で2枚。1枚目=日勤 / 2枚目=夜勤、両面用）
  現在の配置を保存         … JSONファイルとしてダウンロード
  保存した配置を読み込む   … JSONから復元
      ※保存ファイルに secret.csv・ojt.csv 由来の情報は入りません。
        読込後にバッジ表示・違反チェックを使うときは両CSVを再読み込み。

■ CSV作成の最低限ルール（詳細はリファレンス版readmeへ）
  ・文字コードはUTF-8（Excelでは「CSV UTF-8」形式で保存）
  ・1行目はヘッダー行として残す
  ・氏名は全ファイルで月間シフトCSVと同じ表記にそろえる
    （姓名の間のスペースの有無・全角半角まで一致させる）
  ・日をまたぐ夜勤の終了時刻は「32:00」のように24時以降表記で書く
    （翌朝のつもりで「8:00」と書かない）
  ・座席番号は半角数字。複数指定はスペース区切り（半角・全角どちらも可）
    で、入力した順がそのまま優先順位になる
  ・secret.csv の禁止席・固定席・要サポートは1人1行にまとめる
    （同じ人が2行以上あると自動配置が実行できない。隣接禁止だけは複数行可）
  ・座席9番は通常の自動配置（新人固定席やその他スタッフの通常探索など）
    では使いません。ただし固定席・要サポート・教官/OJT同席（対象座席）で
    明示的に9番を指定した場合は例外的に配置され、メッセージ欄に「通常、
    座席9番には配置しませんが、〇〇さんは固定席で指定されていたため配置
    しました」のように理由が表示されます。手動でのドラッグ＆ドロップでは
    従来どおり配置できます。

■ 困ったら
  ・まず「2. メッセージ」欄を読む（エラーは行番号つきで出ます）
