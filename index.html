座席配置ツール

月間シフトCSVを読み込んで自動配置し、必要に応じてドラッグ＆ドロップで調整します（rookie.csv / secret.csv / ojt.csv は任意）。

1CSV読み込み

ここに 月間shift.csv・ojt.csv・rookie.csv・secret.csv をまとめてドラッグ&ドロップ

ファイル名から自動的に振り分けます（ファイル名に shift / ojt / rookie / secret のいずれかを含めてください。月間シフトCSV以外は任意です）

または、個別に選択:

例: 2026-06_shift.csv 未読み込み

CSVの形式について
ファイル必須役割
月間シフトCSV必須1か月分の全出勤情報（ツール側で日付ごとに抽出）
rookie.csv任意新人の固定席（座席5〜8）
secret.csv任意禁止席・固定席・要サポート・隣接禁止・優先フラグ
ojt.csv任意教官とOJT対象者の同席

共通ルール: 文字コードはUTF-8（Excelでは「CSV UTF-8」形式で保存）。氏名は月間シフトCSVと同じ表記にそろえてください。座席番号は半角数字（1〜15）・スペース区切りで、入力した順＝優先順位です。任意のCSVは未読み込みでもエラーにはなりません。

自動配置の処理順序について

役席・GLの別枠（早番・遅番エリア／夜勤GL枠）を先に確定したあと、座席1〜15を次の順で配置します。

優先フラグ → 新人固定席 → 固定席 → 教官・OJT → 要サポート → 隣接禁止・禁止席の対象者（全探索） → その他のスタッフ（出勤時刻が早い順）

座席9番はどの段階でも自動配置の対象外です。指定席に配置できなかった場合は、メッセージを表示したうえで通常の空席探索にフォールバックします。

4夜勤 座席配置

夜勤パネルの見かたについて

夜勤のスタッフ（開始時刻が22:00より遅い、または終了時刻が26:00より遅い人）は、このパネルに配置されます。座席のレイアウト・番号・カードの見かたは日勤と共通です（座席9番が自動配置の対象外である点も同じ）。

夜勤の役席・GLは、1名なら「夜勤GL」枠（右側）へ。2名以上なら1名が「夜勤GL」枠、次の1名が座席10、3人目以降は空いている座席に配置されます。

左側の見出しのない枠は予備枠です。自動配置では使いませんが、カードの一時置き場や印刷後の手書きスペースとして使えます（移動後は「手動変更後 配置違反チェック」で確認してください）。

▶ 夜勤GLの選ばれ方・隣接回避のくわしいルールは 図解マニュアル「自動配置の順番（優先順位）」 を参照

手動変更後 配置違反チェックについて

座席ルールの違反に加えて、日勤・夜勤の入れ違いや、夜勤の役席・GLがいるのに「夜勤GL」枠が空になっているケースも検出します。

教官・OJT本人同士の同席は違反として扱いません。OJT対象者と臨時教官の同席は、エラーではなく「意図した配置か確認してください」という確認メッセージのみ表示します。座席9番への手動配置も違反にはなりません。

▶ くわしくは 図解マニュアル「ボタンと注意点」 を参照

印刷について

「印刷する」ボタンを押すと、座席表の日付を確認する画面が出ます（間違っていればその場で修正できます）。OKを押すと、1ページ目＝日勤、2ページ目＝夜勤のA4各1枚の印刷用ページが新しいタブで開き、そのまま印刷プレビューに進みます（両面コピー用）。

印刷プレビュー画面を誤って閉じてしまった場合は、開いたタブの上部にある「この内容を印刷する」ボタンから、いつでも印刷プレビューをやり直せます。

▶ くわしくは 図解マニュアル「ボタンと注意点」 を参照

配置の保存・読み込みについて

「現在の配置を保存」で、いま表示中の配置（手動調整の内容を含む）をJSONファイルとしてダウンロードします。「保存した配置を読み込む」で、そのJSONファイルを選択すると保存した時点の配置画面が復元されます。

保存ファイルには secret.csv・ojt.csv から推測できる情報（バッジ情報を含む）は一切含まれません。読み込み後にバッジ表示や配置違反チェックを使うには、別途 secret.csv・ojt.csv の読み込みが必要です（既に読み込み済みなら自動的に適用されます）。
