座席配置ツール

月間シフトCSVを読み込んで自動配置し、必要に応じてドラッグ＆ドロップで調整します（rookie.csv / secret.csv / ojt.csv は任意）。

1CSV読み込み

ここに 月間shift.csv・ojt.csv・rookie.csv・secret.csv をまとめてドラッグ&ドロップ

ファイル名から自動的に振り分けます（ファイル名に shift / ojt / rookie / secret のいずれかを含めてください。月間シフトCSV以外は任意です）

または、個別に選択:

例: 2026-06_shift.csv 未読み込み
ojt.csv（任意） 未読み込み
rookie.csv（任意） 未読み込み

CSVの形式について
月間シフトCSV（ヘッダー行あり・UTF-8。1か月分の全出勤情報をまとめて読み込みます）
日付氏名開始時刻終了時刻前残業後残業役割
2026-06-01山田太郎7:3016:30FALSEFALSE役席
2026-06-01後藤四郎11:0022:00TRUEFALSEOP
2026-06-01佐藤花子22:0032:00FALSEFALSEGL

日付は YYYY-MM-DD または YYYY/M/D 形式（2026-06-01 と 2026/6/1 のどちらでも可）。読み込み後、「配置対象日」で日を選ぶとその日の出勤者だけを抽出します（年月はCSVから自動表示）。
終了時刻が24:00を超える場合は日跨ぎを表します（例: 開始22:00・終了32:00 → 当日22:00に出勤し翌日8:00に退勤）。
前残業・後残業がTRUEの場合は残業あり、FALSEの場合は定時という意味です。（カード上で時刻が黄色マーカーと※で表示されます）。
役割は「役席」「GL」「OP」のいずれかです。

役割ごとの配置先
まず夜勤かどうかで振り分けます。夜勤＝開始時刻が22:00より遅い、または終了時刻が26:00より遅いスタッフです。

夜勤でないスタッフ（日勤）
OP … 「3. 日勤 座席配置」の座席グリッド（全15席）に自動配置されます。
役席・GL … 日勤座席グリッド上部の「早番」「遅番」エリア（各2行×3列＝6名まで）に、役席→GLの順に1マス目から出勤時刻が早い順に詰めて配置します。
　※役席・GLの合計が6名を超える分（7人目以降）はどこにも配置されず、メッセージで知らせます。
　※遅番＝開始時刻が12:00以降、または前残業がTRUEかつ開始時刻が10:00以降のスタッフ。それ以外は早番エリアに配置されます。

夜勤のスタッフ
OP … 「4. 夜勤 座席配置」の座席グリッド（日勤と同じ全15席のレイアウト）に自動配置されます。
役席・GL … 人数によって配置先が変わります。
　1名の場合 … 「夜勤GL」枠（右側の枠）の2行1列目に配置します。
　2名以上の場合 … 1名を「夜勤GL」枠2行1列目に配置します（secret.csvで固定席「夜勤GL席」を指定されている人を優先。該当者が複数、または該当者がいない場合はランダム選出）。残りのうち先頭の1名（役席→GLの順・出勤時刻が早い順）は座席10へ、3人目以降は空いている座席へ配置します。
　※「夜勤GL席」に指定されていても選ばれず座席1〜15に配置された人には「夜勤GL席」バッジが付きます。

夜勤の座席配置の優先順位は「優先フラグ ＞ 新人（rookie.csv）＞ 固定席（secret.csv・座席10のリーダー含む）＞ 教官・OJT ＞ 要サポート ＞ 出勤時刻順」です。また夜勤に限り、座席探索の際に同列で隣接する座席を（他に選べる候補がある限り）避けます。固定席などの都合で結果的に隣接するのは問題なく、その場合にメッセージは表示されません。

「隣接禁止」＝対象1と対象2は同じ列の隣接する座席に配置してはいけない（ルール1）。同じ人について複数行書いてもかまいません。
「禁止席」＝対象1のスタッフを、対象座席で指定した座席番号に配置してはいけない（ルール2）。
「固定席」＝対象1のスタッフを、対象座席で指定した座席番号に必ず配置する。複数の座席番号を指定した場合、入力した順が優先順位になります（上の例では高橋次郎さんは7番を優先し、空いていなければ11番。仮にAさんが「1 2」、Bさんが「2 1」と指定していれば、Aさんは1番を、Bさんは2番を優先して配置しようとします）。
「要サポート」＝新人は卒業したものの独り立ちまであと一歩のスタッフを表す種別です。入力形式・複数座席指定時の優先順位のルールは「固定席」と全く同じです（上の例の中村五郎さんは2番を優先し、空いていなければ6番）。配置画面には「要サポ」バッジが付きます。
該当しない列は空欄のままにしてください。対象座席には数字（半角）を、複数指定する場合はスペース（半角・全角どちらも可）区切りで入力してください。
「禁止席」「固定席」「要サポート」は、同じ人を2行以上に分けて書くことはできません。1人につき1行にまとめ、複数の座席はスペース区切りで指定してください（分かれている場合、自動配置を実行できません）。
固定席の対象座席には、座席番号のほかに特別な値「夜勤GL席」も指定できます（上の例の近藤　美穂さんのように）。これは夜勤の役席・GLが2名以上いる日に、「夜勤GL」枠（2行1列目）へ優先的に入れたい人を指定するためのものです。「夜勤GL席」は禁止席・要サポートには指定できません。数字と組み合わせて「夜勤GL席 3」のように書くと「夜勤GL枠か3番のどちらか」という指定になります。異なる複数人が「夜勤GL席」を指定している場合、その日の該当者の中からランダムに1名が選ばれます（選ばれなかった人は通常どおり座席1〜15に配置され、「夜勤GL席」バッジが付きます）。日勤の座席配置には影響しません。
「優先フラグ」は種別を問わずどの行にも指定でき、対象1の氏名に適用されます（半角・全角どちらの数字も可。上の例では渡辺六郎さんに全角「１」を指定していますが、半角の「1」と同じ扱いになります）。数値が入力されている人は、他のどの配置ルールよりも先に処理されます。複数人に優先フラグが入力されている場合は数値が小さい人から順に配置し、同じ数値の場合は「新人 ＞ 固定席 ＞ 教官・OJT ＞ 要サポート ＞ その他」の順、それでも同じなら出勤時刻が早い順に並べます。優先フラグを持つ人が固定席・要サポートの指定も持っていればその候補座席（入力順）を使って配置し、指定がなければ通常の空席探索で配置します。

教官1名につき1行。OJT対象者は最大2名まで（OJT二人目は空欄でもかまいません）。教官・OJT一人目は同じ座席に同席します（この場合に限り、勤務時間が重なっていても同席として扱います）。OJT二人目がいる場合は、教官・OJT一人目の座席とは別に、OJT二人目だけの座席を近くから探します。
対象座席は、教官・OJT一人目が同席する座席の優先順を指定します。空欄なら既定順（15→12→8→他）。座席番号を書くとその座席が先頭に来て、残りは既定順のまま続きます（例:「12」と書くと 12→15→8→他、「12 4」のように半角・全角スペース区切りで複数書くと 12→4→15→8→他 という順になります）。OJT二人目がいる場合のペア席の探索順は、ここで決まる単独時の順を元にプログラム側で自動的に決まるため、ojt.csv側で個別に指定する必要はありません。

配置のされ方（担当人数別）
・教官1名・OJT1名の場合　教官とOJT対象者を同じ座席に同席させます（勤務時間が重なっていても可）。対象座席で指定した座席を先頭にした既定順（未指定なら15→12→8→他）で、まだ誰も座っていない座席を先頭から順に探し、最初に見つかった座席に2人まとめて座らせます。
・教官1名・OJT2名の場合　教官・OJT一人目が同席する座席と、OJT二人目だけが座る座席を、あらかじめ決めた組み合わせ（12番&8番、または15番&14番のどちらかを対象座席の指定から優先して選び、以降は12通りの共通の組み合わせ）の中から近い順に試します。教官・OJT一人目側は時間重複を許可した同席判定、OJT二人目側は通常どおり時間が重ならないことが条件の判定を使います。すべての組み合わせが埋まっていた場合のみ、3名をそれぞれ個別に通常の空席探索で配置します。
・教官1名・OJT2名と教官1名・OJT1名が同じ日に混在する場合　まず教官1名・OJT2名（ペア配置）側から先に配置し、実際に使った座席番号を記録します。続けて教官1名・OJT1名側を配置する際、既定順（15→12→8→他）で空きが見つからなければ、先に記録しておいた教官1名・OJT2名側の座席の「同列で1つ前（行が1つ小さい側）」の座席（例: 12番・8番に配置済みなら11番・7番）を追加候補として試してから、それでも見つからない場合に他の空席を探します。この追加候補により、教官同士がなるべく近くに集まって座りやすくなります。
優先順位は「優先フラグ ＞ 新人 ＞ 固定席 ＞ 教官・OJT ＞ 要サポート ＞ 出勤時刻順」です。教官の通常の役割が役席・GLの場合、その日出勤しているOJT対象者を担当していれば、早番・遅番エリアではなく座席グリッド側に配置されます（OJT対象者がいない日は通常どおり早番・遅番エリアに配置されます）。
担当教官がその日不在の場合、出勤していて担当人数に空きがある（担当中のOJT対象者が2名未満の）他の教官がいれば、そちらへ自動的に振り分けて同席させます（振り分け先の座席の優先順は、振り分け先の教官自身の対象座席を使います）。代わりに担当できる教官が見つからない場合は、OJT対象者は同席する相手がいないためお1人で配置されます。この場合はメッセージ欄で知らせるので、配置画面で手動により臨時の教官役を同じ座席へドラッグ＆ドロップしてください（同席となる勤務時間の重なりは「手動変更後 配置違反チェック」で違反として扱われず、確認を促すメッセージのみ表示されます）。
なお、教官・OJT対象者が新人（rookie.csv記載の上位4名）を兼ねている場合、新人としての固定席（2列目）配置が教官・OJTの同席より優先されるため、教官とは同席しません。

自動配置の処理順序について

「自動配置を実行」を押すと、まず夜勤かどうか・役割（役席／GL／OP）で振り分けたうえで、以下の順に座席を確定していきます。後の順位の人ほど、先に確定した座席は候補から外れます。

早番・遅番エリア／夜勤GL枠（役席・GL）
OPの座席割り当てとは別枠で、役席・GLは早番／遅番エリア（日勤）または夜勤GL枠・座席10（夜勤）に、役席→GLの順・出勤時刻が早い順で先に確定されます（詳しくは上の「CSVの形式について」を参照）。

座席グリッド（OP、および早番・遅番/夜勤GL枠に入らなかった役席・GL）
1. 優先フラグ（secret.csv）… 数値が小さい人から順に配置。固定席・要サポートの指定があればその候補座席（入力順）を使用し、なければ通常の空席探索。同数値の場合は「新人＞固定席＞教官・OJT＞要サポート＞その他」→出勤時刻順で並べます。
2. 新人固定席（rookie.csv、上位4名・OPのみ）… 新人度合いが小さい人から、2列目の座席5番→6番→7番→8番の順に上から詰めて配置。
3. 固定席（secret.csv）… 候補座席の数が少ない人ほど先に配置（同数なら出勤時刻順）。複数候補がある場合は入力順を優先。
4. 教官・OJT（ojt.csv）… 教官とOJT一人目を同席させ、OJT二人目がいれば近くの座席を別途確保。
5. 要サポート（secret.csv）… 固定席と同じ並び順ルール。
6. secret.csv記載スタッフ（隣接禁止・禁止席の対象者）… 全探索（枝刈り付きbacktrack）で、全員を配置できる組み合わせを実際にすべて探し、その中から一番良さそうな案を採用します（詳しくは下記）。
7. その他スタッフ … 出勤時刻が早い順。
ここまでの各段階で、すでに配置済みの人は後の段階では処理されません。指定席に配置できなかった場合は、その場でメッセージを表示したうえで通常の空席探索にフォールバックします。
なお夜勤に限り、座席探索の際は同列で隣接する座席を（他に選べる候補がある限り）避けます。

secret.csv記載スタッフの配置（全探索backtrack）について
6.のステップ（隣接禁止・禁止席の対象者）だけは、貪欲な当てはめではなく全探索で行います。1人ずつ「今置ける座席が一番少ない人」から座席を試し、途中で他の誰かが置けなくなった時点でその組み合わせを打ち切って別の組み合わせを試す、という探索を尽くします。これにより「本当は解けるのに、たまたま見つからずあふれてしまう」ことを防ぎます。
見つかった組み合わせのうち一番良さそうな案（座席の埋まり方の偏りが少なく、勤務時間がぴったり接する同席が少ないもの）を自動的に採用します。「3. 日勤 座席配置」「4. 夜勤 座席配置」の遅番枠・夜勤GL枠の右にある「次の案」ボタンで、他に見つかった組み合わせに順番に切り替えられます（secret.csv対象者以外の座席は変わりません）。実行可能な組み合わせが1通りしかなかった場合は他に切り替え先がないため、「次の案」ボタンは押せない状態になり、メッセージ欄にも「最も良さそうな案を採用しています」「次の案ボタンで切り替えられます」といった案内は表示されず、見つかった件数のみを知らせます。「その他の座席をシャッフル」ボタンでは、secret.csv対象者側の配置はそのままに、それ以外のスタッフの座席だけをランダムに振り直せます。どちらのボタンも、押すたびに今の座席表を置き換えます（手動で調整した内容は失われます）。
全員を配置できる組み合わせが1件も見つからなかった場合（secret.csvの条件同士が矛盾している等）や、制限時間内に探索が終わらなかった場合は、従来どおりの配置方法（出勤時刻順への当てはめ）にフォールバックし、メッセージ欄で知らせます。

操作方法について

座席カードや早番・遅番エリアのカードは、ドラッグ＆ドロップで人単位の入れ替えができます。同じ枠内はもちろん、早番⇔遅番、座席⇔あふれなど、別の枠との間でも自由に移動できます。
各カードの氏名の右にある✎アイコンから、氏名・時間の手入力修正や、その日の配置からの削除ができます。
ドラッグ操作は配置ルールを自動チェックしないため、手動で動かした後は「手動変更後 配置違反チェック」で確認してください。配置違反チェック・印刷・配置の保存/読み込みのボタンは、下の「4. 夜勤 座席配置」パネルの末尾にあります（日勤・夜勤の両方が対象です）。

夜勤パネルの見かたについて

夜勤のスタッフ（開始時刻が22:00より遅い、または終了時刻が26:00より遅い人）は、このパネルに配置されます。座席のレイアウト・番号（1〜15）・カードの見かたは日勤と共通です。

夜勤の役席・GLが1名の場合は「夜勤GL」枠（右側）の2行1列目に配置されます。2名以上の場合は、1名が「夜勤GL」枠2行1列目（secret.csvで固定席「夜勤GL席」を指定されている人を優先。該当者が複数、またはいない場合はランダム選出）、次の1名が座席10、3人目以降は空いている座席に配置されます（「夜勤GL席」を指定されていても選ばれなかった人には座席カードに「夜勤GL席」バッジが付きます）。
OPの座席配置の優先順位は「優先フラグ ＞ 新人 ＞ 固定席 ＞ 教官・OJT ＞ 要サポート ＞ 出勤時刻順」です。また夜勤に限り、同列で隣接する座席をできるだけ避けて配置します（固定席などの都合で隣接した場合はそのままで問題ありません）。

左側の見出しのない枠は予備枠です。自動配置では使いませんが、カードの一時置き場や印刷後の手書きスペースとして使えます。カードは日勤と同じく、どのエリアの間でも自由にドラッグで移動できます（移動後は「手動変更後 配置違反チェック」で確認してください。日勤・夜勤を入れ違えた場合もこのチェックで検出されます）。

手動変更後 配置違反チェックについて

日勤・夜勤それぞれの座席グリッドのルール違反に加えて、日勤・夜勤の入れ違い（夜勤の人が日勤側にいる、など）や、夜勤の役席・GLがいるのに「夜勤GL」枠が空になっているケースも検出します。
同じ座席に勤務時間が重なる2名がいる場合、通常は違反（エラー）として報告しますが、ojt.csvで紐づく教官・OJT本人同士の同席は違反として扱いません。OJT対象者が絡む同席で、ojt.csv上の組み合わせと一致しない場合（担当教官が不在で臨時に別の方を割り当てた場合など）は、エラーではなく「OJTと臨時教官の組み合わせであれば問題ありません。意図した配置か確認してください」という確認メッセージを表示します。

印刷について

「印刷用ページを開く」ボタンから、1ページ目＝日勤、2ページ目＝夜勤のA4各1枚で印刷用ページを開きます（両面コピー用）。

配置の保存・読み込みについて

「現在の配置を保存」で、いま表示中の配置（手動調整の内容を含む）をJSONファイルとしてダウンロードします（ブラウザの既定のダウンロード先に保存されます）。
「保存した配置を読み込む」で、ダウンロードしておいたJSONファイルを選択すると、保存した時点の配置画面が復元されます。
※保存ファイルには secret.csv・ojt.csv から推測できる情報（固定席・禁止席・要サポート・教官・OJTなどのバッジ情報を含む）は一切含まれません。読み込み後に配置違反チェックやバッジ表示を使うには、別途 secret.csv・ojt.csv の読み込みが必要です（既に読み込み済みなら自動的に適用されます）。
