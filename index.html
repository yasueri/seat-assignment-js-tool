座席配置ツール

月間シフトCSV / rookie.csv / secret.csv を読み込んで自動配置し、必要に応じてドラッグ＆ドロップで調整します。

1CSV読み込み

ここに 月間シフトCSV・rookie.csv・secret.csv をまとめてドラッグ&ドロップ

ファイル名から自動的に振り分けます（ファイル名に shift / rookie / secret のいずれかを含めてください）

または、個別に選択:

rookie.csv 未読み込み
secret.csv 未読み込み
例: 2026-06_shift.csv 未読み込み
CSVの形式について
月間シフトCSV（ヘッダー行あり・UTF-8。1か月分の全出勤情報をまとめて読み込みます）
日付氏名開始時刻終了時刻前残業後残業役割
2026-06-01山田太郎7:3016:30FALSEFALSE役席
2026-06-01後藤四郎11:0022:00TRUEFALSEOP
2026-06-01佐藤花子22:0032:00FALSEFALSEGL

日付は YYYY-MM-DD 形式。読み込み後、「配置対象日」で日を選ぶとその日の出勤者だけを抽出します（年月はCSVから自動表示）。
終了時刻が24:00を超える場合は日跨ぎを表します（例: 開始22:00・終了32:00 → 当日22:00に出勤し翌日8:00に退勤）。
前残業・後残業は TRUE / FALSE で入力してください。前残業=開始時刻が残業、後残業=終了時刻が残業という意味です（カード上で時刻が黄色く表示されます）。
役割は「役席」「GL」「OP」のいずれかです。

役割ごとの配置先
まず夜勤かどうかで振り分けます。夜勤＝開始時刻が22:00より遅い、または終了時刻が26:00より遅いスタッフです。

夜勤でないスタッフ（日勤）
OP … 「3. 日勤 座席配置」の座席グリッド（全15席）に自動配置されます。
役席・GL … 日勤座席グリッド上部の「早番」「遅番」エリア（各2行×3列＝6名まで）に、役席→GLの順に1マス目から出勤時刻が早い順に詰めて配置します。
　※役席・GLの合計が6名を超える分（7人目以降）はどこにも配置されず、メッセージで知らせます。
　※遅番＝開始時刻が12:00以降、または前残業がTRUEかつ開始時刻が10:00以降のスタッフ。それ以外は早番エリアに配置されます。

夜勤のスタッフ
OP … 「4. 夜勤 座席配置」の座席グリッド（日勤と同じ全15席のレイアウト）に自動配置されます。
役席・GL … 人数によって配置先が変わります。
　1名の場合 … 「夜勤GL」枠（右側の枠）の2行1列目に配置します。
　2名以上の場合 … 1名を「夜勤GL」枠2行1列目に配置します（secret.csvで席固定「夜勤GL席」を指定されている人を優先。該当者が複数、または該当者がいない場合はランダム選出）。残りのうち先頭の1名（役席→GLの順・出勤時刻が早い順）は座席10へ、3人目以降は空いている座席へ配置します。
　※「夜勤GL席」に指定されていても選ばれず座席1〜15に配置された人には「夜勤GL席」バッジが付きます。

夜勤の座席配置の優先順位は「席固定（secret.csv・座席10のリーダー含む）＞ 新人固定席（rookie.csv）＞ 出勤時刻順」です。また夜勤に限り、座席探索の際に同列で隣接する座席を（他に選べる候補がある限り）避けます。席固定などの都合で結果的に隣接するのは問題なく、その場合にメッセージは表示されません。

rookie.csv（ヘッダー行あり）数値が小さいほど新人。同数値の場合は月間シフトCSVでその日の後ろの行の人がより新人として扱われます。（対象はOPのみ）
氏名新人度合い
山田太郎1
secret.csv（ヘッダー行あり）「種別」列でルールの種類を区別します。
種別対象1対象2対象座席
隣接禁止山田太郎佐藤花子
禁止席鈴木一郎5
席固定高橋次郎7 11
席固定近藤　美穂夜勤GL席

「隣接禁止」＝対象1と対象2は同じ列の隣接する座席に配置してはいけない（ルール1）。同じ人について複数行書いてもかまいません。
「禁止席」＝対象1のスタッフを、対象座席で指定した座席番号に配置してはいけない（ルール2）。
「席固定」＝対象1のスタッフを、対象座席で指定した座席番号に必ず配置する。他のどのルールよりも最優先で配置されます（上の例では高橋次郎さんは7番か11番のどちらか）。
該当しない列は空欄のままにしてください。対象座席には数字（半角）を、複数指定する場合はスペース（半角・全角どちらも可）区切りで入力してください。
「禁止席」「席固定」は、同じ人を2行以上に分けて書くことはできません。1人につき1行にまとめ、複数の座席はスペース区切りで指定してください（分かれている場合、自動配置を実行できません）。
席固定の対象座席には、座席番号のほかに特別な値「夜勤GL席」も指定できます（上の例の近藤　美穂さんのように）。これは夜勤の役席・GLが2名以上いる日に、「夜勤GL」枠（2行1列目）へ優先的に入れたい人を指定するためのものです。「夜勤GL席」は禁止席には指定できません。数字と組み合わせて「夜勤GL席 3」のように書くと「夜勤GL枠か3番のどちらか」という指定になります。異なる複数人が「夜勤GL席」を指定している場合、その日の該当者の中からランダムに1名が選ばれます（選ばれなかった人は通常どおり座席1〜15に配置され、「夜勤GL席」バッジが付きます）。日勤の座席配置には影響しません。

4夜勤 座席配置（ドラッグ＆ドロップで人単位の入れ替えができます）

夜勤パネルの見かたについて

夜勤のスタッフ（開始時刻が22:00より遅い、または終了時刻が26:00より遅い人）は、このパネルに配置されます。座席のレイアウト・番号（1〜15）・カードの見かたは日勤と共通です。

夜勤の役席・GLが1名の場合は「夜勤GL」枠（右側）の2行1列目に配置されます。2名以上の場合は、1名が「夜勤GL」枠2行1列目（secret.csvで席固定「夜勤GL席」を指定されている人を優先。該当者が複数、またはいない場合はランダム選出）、次の1名が座席10、3人目以降は空いている座席に配置されます（「夜勤GL席」を指定されていても選ばれなかった人には座席カードに「夜勤GL席」バッジが付きます）。
OPの座席配置の優先順位は「席固定 ＞ 新人固定席 ＞ 出勤時刻順」です。また夜勤に限り、同列で隣接する座席をできるだけ避けて配置します（席固定などの都合で隣接した場合はそのままで問題ありません）。

左側の見出しのない枠は予備枠です。自動配置では使いませんが、カードの一時置き場や印刷後の手書きスペースとして使えます。カードは日勤と同じく、どのエリアの間でも自由にドラッグで移動できます（移動後は「手動変更後 配置違反チェック」で確認してください。日勤・夜勤を入れ違えた場合もこのチェックで検出されます）。

保存した配置の読み込み

ドラッグ操作は配置ルールを自動チェックしません。手動で動かした後は「手動変更後 配置違反チェック」ボタンで違反がないか確認してください（日勤・夜勤の両方の座席グリッドのルール違反に加え、日勤・夜勤の入れ違い＝夜勤の人が日勤側にいる等や、夜勤の役席・GLがいるのに「夜勤GL」枠が空になっているケースも検出します）。
印刷用ページは、1ページ目＝日勤、2ページ目＝夜勤のA4各1枚で出力されます（両面コピー用）。
「現在の配置を保存」で、いま表示中の配置（手動調整の内容を含む）を index.html のあるフォルダ内の save フォルダへJSONファイルとして保存します（saveフォルダがなければ自動で作成されます）。初回はブラウザのダイアログで「index.htmlのあるフォルダ」を選択し、アクセスを許可してください。
「保存した配置の読み込み」は、「一覧を更新」でsaveフォルダ内の保存ファイルを取得し、選んで「読み込み」を押すと保存した時点の配置画面が復元されます。
※保存ファイルには secret.csv から推測できる情報（席固定・禁止席などのバッジ情報を含む）は一切含まれません。読み込み後に配置違反チェックやバッジ表示を使うには、別途 secret.csv の読み込みが必要です（既に読み込み済みなら自動的に適用されます）。
