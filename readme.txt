===============================================
座席配置ツール (Seat Assignment Tool)
===============================================
最終更新: 2026年7月

■ 概要
出勤スタッフの氏名・勤務時間が書かれたCSVを読み込み、あらかじめ決めたルール
（新人の固定席、隣接禁止、座席禁止など）に従って座席へ自動的に割り振るツールです。
割り振り結果はドラッグ&ドロップで手動調整でき、最終的にCSVとして出力できます。


■ 動作環境
- ブラウザ（Google Chrome、Microsoft Edgeなど）があれば動作します
- Node.jsなど追加のインストールは一切不要です
- サーバーも不要です。index.html をダブルクリックして開くだけで使えます
- 完全にオフラインで動作します（外部通信は行いません）


■ ディレクトリ構成
  index.html          … 画面本体（これをブラウザで開く）
  css/
    style.css         … 見た目のスタイル
  js/
    csv.js            … CSVの読み書き・解析（shift/newbee/secretそれぞれの検証）
    algorithm.js      … 座席の定義・配置ロジック（DOMに依存しない）
    ui.js             … 画面描画・ドラッグ&ドロップ・ファイル入出力


■ 使い方
  1. index.html をダブルクリックしてブラウザで開く
  2. 「1. CSV読み込み」で shift.csv / newbee.csv / secret.csv を選択する
  3. 「自動配置を実行」ボタンを押す
  4. 必要であれば座席をドラッグ&ドロップで手動調整する
  5. 「CSVを出力」ボタンを押して結果を保存する


■ 入力CSVの形式（すべてヘッダー行あり・文字コードUTF-8）

  [shift.csv] その日出勤するスタッフの氏名と勤務時間
    列: 氏名, 出勤時刻, 退勤時刻
    例:
      氏名,出勤時刻,退勤時刻
      山田太郎,9:00,18:00

  [newbee.csv] 新人スタッフとその新人度合い
    列: 氏名, 新人度合い
    例:
      氏名,新人度合い
      山田太郎,1
    ※ 数値が小さいほど新人（優先的に固定席へ配置）
    ※ 新人は最大4人まで。座席の2列目（1〜4行目）に新人度合いの小さい順で固定配置
    ※ shift.csvにその日の出勤記載がない人は対象外

  [secret.csv] 絶対に守るべき配置ルール
    列: 種別, 対象1, 対象2, 禁止行, 禁止列
    種別は「隣接禁止」または「座席禁止」のいずれか

    隣接禁止: 対象1と対象2を同じ列の隣接する行に配置してはいけない
      例: 隣接禁止,山田太郎,佐藤花子,,

    座席禁止: 対象1を、禁止行・禁止列で指定した座席に配置してはいけない
      例: 座席禁止,鈴木一郎,,1,2

    ※ 該当しない列は空欄のままにする
    ※ 隣接禁止は勤務時間が重なっているかどうかに関係なく常に適用される
      （急な残業で勤務時間が伸びて隣接してしまうケースを避けるため）


■ 座席のレイアウト（全15席）
    (1,1) (1,2) (1,3) (1,4)
    (2,1) (2,2) (2,3) (2,4)
    (3,1) (3,2) (3,3) (3,4)
    (4,1) (4,2) (4,3)
  ※ (4,4) は存在しない


■ 配置の優先順位
  1. 新人（newbee.csv記載者）… 2列目に固定配置
  2. secret.csv記載者 … 出勤時刻が早い順
  3. その他のスタッフ … 出勤時刻が早い順
  ※ 出勤時刻が同じ場合は、shift.csvの後ろの行に記載されている人を先に処理する


■ 相席について
  勤務時間が重ならなければ、1つの座席に最大2名まで配置する。
  境界時刻がちょうど一致する場合（例: 9:00-13:00 と 13:00-18:00）は、
  空席があれば別の席に分け、席が足りない場合のみ相席にする。


■ あふれについて
  出勤人数が多く、全員を座席に配置しきれない場合は「あふれ」として扱う。
  出力CSVの6列目に一覧が入る。


■ 出力CSVについて
  1〜4列目: 各列の座席（行の順）
  5列目  : 空欄
  6列目  : あふれたスタッフの一覧
  ファイル名は「座席配置_YYYYMMDD_HHMM.csv」がデフォルト。
  対応ブラウザ（Chrome/Edgeなど）では保存先を選ぶダイアログが表示される。
  対応していないブラウザでは、通常のダウンロードフォルダに保存される。


■ 手動調整（ドラッグ&ドロップ）について
  座席のカードは人単位でドラッグ&ドロップして入れ替えできる。
  手動での入れ替えは「隣接禁止」「座席禁止」のルールを自動チェックしないため、
  鍵アイコン（🔒）が付いている人（secret.csv対象者）を動かす際は目視で確認すること。


■ サンプルCSVについて
  shift.csv（20名分）、newbee.csv、secret.csv のサンプルを別途用意しています。
  sample-dataフォルダを参照してください。
  実際のCSVを作成する際のひな形・動作確認用としてご利用いただけます。


■ 既知の制限事項
  - ドラッグ&ドロップ後の配置ルール違反は自動検知しない（目視確認が必要）
  - CSVの文字コードは現在UTF-8のみ対応（Shift-JIS対応は今後の課題）
  - 出力ファイル名・保存先は現時点では固定の初期値のみ


■ 今後、機能を変更したい場合
  - CSVの列や読み込み処理を変えたい   → js/csv.js
  - 座席のレイアウトや配置ルールを変えたい → js/algorithm.js
  - 画面の見た目や操作性を変えたい     → css/style.css, js/ui.js
