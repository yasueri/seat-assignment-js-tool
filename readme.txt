========================================
座席配置ツール readme
========================================

■ 概要
月間シフトCSVを読み込み、指定した日の座席配置を自動計算するブラウザ完結型ツールです。
rookie.csv・secret.csv・ojt.csvを読み込ませると、該当するルールを使って自動配置します。

サーバー・インターネット接続は不要で、index.html をブラウザで開くだけで動作します。


■ ファイル構成
  任意のフォルダ/
  ├─ index.html        ... 本体（ブラウザで開くファイル）
  ├─ css/
  │   └─ style.css    ... 画面デザイン（配色・レイアウト・カードのスタイル等）
  ├─ js/
  │   ├─ csv.js       ... CSVの読み込み・解析・入力チェック
  │   ├─ algorithm.js ... 自動配置ロジック（座席の割り当て計算。貪欲+MRVに加え、
  │   │                     secret.csv対象者＝隣接禁止・禁止席の対象者専用の
  │   │                     全探索＝枝刈り付きbacktrackロジックも含む）
  │    └─ ui.js       ... 画面表示・ドラッグ＆ドロップ・手動編集、
  │                         違反チェック、印刷、保存/読み込み等の画面制御
  └─readme.txt         ... このファイル


■ 基本的な使い方
  1. 画面上部の枠に、月間シフトCSV（必須）と ojt.csv / rookie.csv / secret.csv（任意）を
     まとめてドラッグ＆ドロップするか、各ボタンから個別に選択します。
     ※ ファイル名に "shift" "ojt" "rookie" "secret" のいずれかを含めると自動で振り分けられます。
  2. 月間シフトCSVの読み込みが終わると「配置対象日」を選べるようになるので、配置したい日を選びます。
  3. 「自動配置を実行」を押すと、その日のスタッフが座席へ自動配置されます。
  4. 配置後は座席カードをドラッグ＆ドロップして手動で調整できます（鉛筆アイコンから氏名・時刻の編集も可能）。
  5. 「現在の配置を保存」でJSONファイルとしてダウンロードし、「保存した配置を読み込む」で復元できます。
     ※ 保存ファイルには secret.csv・ojt.csv 由来の情報（固定席・禁止席・教官／OJTなど）は含まれません。
       保存データを読み込んだ後にバッジ表示や違反チェックを使う場合は、secret.csv・ojt.csvを
       別途読み込み直してください（同じセッション内で既に読み込み済みなら自動的に適用されます）。

  各項目の詳しい判定ルール（役割ごとの座席、夜勤・遅番の判定基準、優先順位など）は
  画面内の「▼ 座席カードの見かたについて」「▼ 操作方法について」の折りたたみ欄にまとめてあります。

■ CSVファイル仕様
以下はいずれも1行目がヘッダー行、UTF-8（BOM付きでも可）のCSVです。
文字コードや列の位置がずれるとヘッダーチェックで警告が出ますが、処理自体は列の位置で続行します。

--------------------------------------------
(1) 月間シフトCSV（例: 2026-06_shift.csv）※必須
--------------------------------------------
列: 日付, 氏名, 開始時刻, 終了時刻, 前残業, 後残業, 役割
  日付     … "YYYY-MM-DD" または "YYYY/M/D" 形式（例: 2026-06-01, 2026/6/1）
  氏名     … 同じ日付・氏名の重複行は不可（最初の行のみ使用）
  開始/終了時刻 … "HH:MM" 形式。日をまたぐ夜勤は24時以降の延長表記（例: 31:00 = 翌7:00）で入力
  前残業/後残業 … TRUE または FALSE（空欄はFALSE扱い）
  役割     … "役席" "GL" "OP" のいずれか
1か月分をまとめて入力し、ツール側で日付ごとに抽出します。

--------------------------------------------
(2) rookie.csv（新人リスト）※任意
--------------------------------------------
列: 氏名, 新人度合い
  新人度合い … 数値。小さいほど新人として優先扱い（同数値の場合は月間シフトCSV内で
              その日の後ろの行にある人がより新人として扱われる）
未読み込みの場合、新人向けの固定席ルールを使わずに配置します。
新人度合いが小さい人から順に、2列目の座席5番→6番→7番→8番へ上から詰めて配置されます
（対象は最大4名まで。5人目以降は新人固定席を使わず通常どおり配置されます）。

--------------------------------------------
(3) secret.csv（禁止席・固定席・要サポート・隣接禁止・優先フラグ）※任意
--------------------------------------------
列: 種別, 対象1, 対象2, 対象座席, 優先フラグ
  種別     … "禁止席" "固定席" "要サポート" "隣接禁止" のいずれか
  対象1    … 対象者の氏名（隣接禁止の場合は1人目）
  対象2    … 隣接禁止の相手の氏名（禁止席／固定席／要サポートでは空欄）
  対象座席 … 座席番号（1〜15）を半角・全角スペース区切りで複数指定可。入力順が優先順位になる。
              固定席のみ特別な値 "夜勤GL席" も指定可（禁止席・要サポートには指定不可）
  優先フラグ … 種別を問わずどの行にも指定可。対象1の氏名に適用され、値が小さいほど
              他のどのルールよりも先に配置される（複数行で異なる値があれば最小値を採用）
同じ人物が同じ種別で複数行に分かれていると重複として検出され、配置を止める判断に使われます。

--------------------------------------------
(4) ojt.csv（教官・OJTの組み合わせ）※任意
--------------------------------------------
列: 教官名, OJT一人目, OJT二人目, 対象座席
  教官名   … 1名につき1行（同じ教官が複数行にまたがるとエラー）
  OJT一人目 … 必須。OJT二人目は空欄可（担当が1名のみの日）
  対象座席 … 単独配置（教官とOJT一人目のみ同席）の候補座席の優先順を、座席番号を
              半角・全角スペース区切りで指定。空欄なら既定順（15→12→8→他）。
              例: "12" と書くと 12→15→8→他、"12 4" なら 12→4→15→8→他 の順になる。
              OJT二人目がいる場合のペア席の探索順は、この指定から自動計算されるため
              ojt.csv側でペアの座席番号を別途指定する必要はありません。

  配置のされ方（担当人数別）:
    ・教官1名・OJT1名の場合
        教官とOJT対象者を同じ座席に同席させます（この組み合わせに限り、勤務時間が
        重なっていても同席可）。対象座席で指定した座席を先頭にした既定順
        （未指定なら15→12→8→他）で、まだ誰も座っていない座席を先頭から順に探し、
        最初に見つかった座席に2人まとめて座らせます。

    ・教官1名・OJT2名の場合
        教官・OJT一人目が同席する座席と、OJT二人目だけが座る座席を、あらかじめ
        決めたペアの組み合わせの中から近い順に試します（対象座席の指定から
        12番&8番 と 15番&14番のどちらを先に試すかが決まり、その後は12通りの
        共通の組み合わせが続きます）。教官・OJT一人目側は時間重複を許可した同席
        判定、OJT二人目側は通常どおり時間が重ならないことが条件の判定を使います。
        すべての組み合わせが埋まっていた場合のみ、3名をそれぞれ個別に通常の
        空席探索で配置します。

    ・教官1名・OJT2名と教官1名・OJT1名が同じ日に混在する場合
        教官1名・OJT2名（ペア配置）側を先に配置し、実際に使った座席番号を記録
        します。続けて教官1名・OJT1名側を配置する際、既定順（15→12→8→他）で
        空きが見つからなければ、先に記録しておいた教官1名・OJT2名側の座席の
        「同列で1つ前（行が1つ小さい側）」の座席（例: 12番・8番に配置済みなら
        11番・7番）を追加候補として試してから、それでも見つからない場合に他の
        空席を探します。この追加候補により、教官同士がなるべく近くに集まって
        座りやすくなります。


■ 座席配置の順番（優先順位）
自動配置は役席・GL枠（早番/遅番エリア、夜勤GL枠）を別枠で先に確定したうえで、
座席1〜15については以下の順番でスタッフを割り当てます。上のステップで配置済みの人は
後のステップの対象から除外されます。

  0. 優先フラグ対象者（secret.csv「優先フラグ」列に値がある人）
     全ルールの中で最優先。数値が小さい人から先に配置します。
     同じ数値の人が複数いる場合は「新人 → 固定席 → 教官・OJT → 要サポート → その他」の順、
     さらに同じ場合は出勤時刻が早い順（同時刻ならCSVで後ろの行の人を先に）で並べます。
     本人が固定席／要サポートの指定も持っていればその候補座席（入力順）へ、
     持っていなければ通常の空席探索で配置します。

  1. 新人固定席（rookie.csvがある場合）
     新人度合いが小さい人から順に、2列目の座席5番→6番→7番→8番へ上から詰めて配置します
     （最大4名まで）。同数値の場合は月間シフトCSV内でその日の後ろの行にある人を優先します。
     指定枠に座れなかった場合は次のステップに回さず、優先的に通常探索へ回します。

  2. 固定席（secret.csv「固定席」）
     候補座席の数が少ない人ほど先に配置します（同数なら出勤時刻が早い順）。
     複数の候補座席がある場合は、secret.csvに入力した順がそのまま優先順位になります。

  3. 教官・OJT（ojt.csvがある場合）
     固定席の次に配置します。教官とOJT一人目は同じ座席に同席し、OJT二人目がいる場合は
     別途ペアの座席を探します。担当教官が本日不在の場合は、枠に空きのある他の教官へ
     自動的に振り分けます（振り分け先がなければOJT対象者のみで配置）。

  4. 要サポート（secret.csv「要サポート」）
     固定席と同じ並び順のルール（候補座席数が少ない人優先、同数なら出勤時刻順）で配置します。

  5. secret.csv記載スタッフ（隣接禁止・禁止席の対象者のうち、上記までに未配置の人）
     貪欲な当てはめではなく、全探索（枝刈り付きbacktrack）で「全員を配置できる組み合わせ」を
     実際にすべて探します。1人ずつ「今置ける座席が一番少ない人」から座席を試し、途中で
     他の誰かが置けなくなった時点でその組み合わせを打ち切り、別の組み合わせを試す、
     という探索を尽くすため、貪欲法のように「本当は解けるのに、たまたま見つからず
     あふれてしまう」ことがありません。見つかった組み合わせのうち、座席の埋まり方の
     偏りが少なく、勤務時間がぴったり接する同席が少ないものを自動的に採用します。
     全員を配置できる組み合わせが1件も見つからなかった場合（secret.csvの条件同士が
     矛盾している等）や、制限時間（既定2秒）内に探索が終わらなかった場合のみ、
     従来どおり出勤時刻が早い順への当てはめにフォールバックします。

     「日勤 座席配置」「夜勤 座席配置」それぞれの遅番枠・夜勤GL枠の右にある
     「次の案」ボタンで、見つかった他の組み合わせ（最大20件）に順番に切り替えられます
     （secret.csv対象者以外の座席は変わりません）。実行可能な組み合わせが1通りしか
     見つからなかった場合は、そもそも複数の案から選んで採用したわけではなく、切り替え先の
     案も存在しないため、「次の案」ボタンは押せない状態になり、メッセージ欄にも
     「最も良さそうな案を採用しています」「次の案ボタンで切り替えられます」といった案内は
     表示されず、見つかった件数のみを知らせます。「その他の座席をシャッフル」
     ボタンでは、secret.csv対象者側の配置はそのままに、6.のその他スタッフの座席だけを
     ランダムに振り直せます。どちらのボタンも、押すたびに今の座席表を置き換えます
     （手動で調整した内容は失われるため、案を決めてから手動で微調整することを
     おすすめします）。座席が変わった人のカードは一瞬光って分かります。

  6. その他スタッフ
     残り全員を出勤時刻が早い順に、空いている座席へ配置します。

  ※ 役席・GL枠（早番/遅番エリア）は座席1〜15とは別枠で、役席→GLの順・出勤時刻が早い順に
     1マス目から詰めて配置します（1枠1名、合計6名まで）。
  ※ 夜勤の役席・GLも座席1〜15とは別に、夜勤GL枠（1名）と座席10（強制配置）を優先的に
     決めたうえで、残りは通常の座席配置に合流します。

■ 注意事項
  ・本ツールはオフライン動作前提のため、外部ライブラリやサーバーへの通信は行いません。
  ・CSVの文字コードはUTF-8を推奨します（Excelで保存する場合は「CSV UTF-8」形式を選択してください）。
  ・入力エラーがあっても自動配置自体は止まらず、画面下部のメッセージ欄に警告として表示されます。
    配置結果に反映されない行がないか、実行後にメッセージ欄を確認してください。
