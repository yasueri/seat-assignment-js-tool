========================================
座席配置ツール readme ver0.5.7.4
========================================
■ 概要
月間シフトCSVなどを読み込み、
指定した日の座席配置を自動計算するブラウザ完結型ツールです。

サーバー・インターネット接続は不要で、
index.htmlをブラウザで開くだけで動作します。


■ ファイル構成
  任意のフォルダ/
  ├─ index.html        ... 本体
  ├─ manual.html       ... マニュアル
  ├─ css/
  │   └─ style.css    ... 画面デザイン
  ├─ js/
  │   ├─ csv.js       ... CSVの読み込み・解析・入力チェック
  │   ├─ algorithm.js ... 自動配置ロジック
  │   └─ ui.js        ... 画面制御
  └─ readme.txt        ... このファイル


■ 操作方法
manual.htmlを参照してください。
