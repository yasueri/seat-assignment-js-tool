====================================================================
 座席配置ツール（座席配置ツール ver4.6）README
====================================================================

概要
--------------------------------------------------------------------
コールセンターの日々の座席配置を自動化する、ブラウザ完結型のツールです。
サーバーやNode.js等は一切使用せず、index.html をブラウザで開くだけで
動作します（社内ネットワークの制約下でも動作するよう設計）。

・月間シフトCSV / rookie.csv / secret.csv の3種類のCSVを読み込み
・指定した日の出勤者を、ルールに沿って15席の座席グリッドへ自動配置
・日勤／夜勤それぞれに対応（夜勤は専用の配置ロジック）
・配置後はドラッグ＆ドロップで手動調整可能
・手動調整後の違反チェック、印刷用ページの出力に対応
・現在の配置をJSONファイルとして保存し、後日読み込んで復元可能
　（保存ファイルにはsecret.csv由来の情報は一切含まれません＝プライバシー配慮）


ファイル構成
--------------------------------------------------------------------
  任意のフォルダ/
  ├─ index.html        ... 画面のHTML構造。js/css を相対パスで読み込みます
  ├─ css/
  │   └─ style.css    ... 画面デザイン（配色・レイアウト・カードのスタイル等）
  └─ js/
      ├─ csv.js        ... CSVの読み込み・パース・バリデーション
      ├─ algorithm.js  ... 座席自動配置のロジック本体（ルール判定・配置探索）
      └─ ui.js         ... 画面描画、ドラッグ＆ドロップ、編集、
                             違反チェック、印刷、保存/読み込み等の画面制御

使い方の流れ
--------------------------------------------------------------------
1. index.html をブラウザ（Chrome等）で開く
2. 「1. CSV読み込み」で3つのCSVをドラッグ&ドロップ、または個別選択
   （ファイル名に shift / rookie / secret のいずれかを含めると
   　ドラッグ&ドロップ時に自動振り分けされます）
3. 月間シフトCSV読み込み後、「配置対象日」で配置したい日を選択
4. 「自動配置を実行」ボタンを押す
   → 「2. メッセージ」に処理結果（警告・エラー等）が表示される
   → 「3. 日勤 座席配置」「4. 夜勤 座席配置」に結果が描画される
5. 必要に応じてドラッグ&ドロップで手動調整
   （調整後は「手動変更後 配置違反チェック」で確認）
6. 「印刷用ページを開く」で日勤1ページ目・夜勤2ページ目のA4印刷用
   ページを表示（両面印刷を想定）
7. 「現在の配置を保存」で配置状況をJSONファイルとしてダウンロード。
   後日「保存した配置を読み込む」で復元可能


CSVの仕様
--------------------------------------------------------------------
■ 月間シフトCSV（1か月分の全出勤情報。UTF-8・ヘッダー行あり）
  列: 日付, 氏名, 開始時刻, 終了時刻, 前残業, 後残業, 役割

  例:
    2026-06-01,山田太郎,7:30,16:30,FALSE,FALSE,役席
    2026-06-01,後藤四郎,11:00,22:00,TRUE,FALSE,OP
    2026-06-01,佐藤花子,22:00,32:00,FALSE,FALSE,GL

  ・日付は YYYY-MM-DD または YYYY/M/D 形式（内部でYYYY-MM-DDに正規化）
  ・終了時刻が24:00を超える場合は日跨ぎ表記（例: 22:00〜32:00＝翌8:00退勤）
  ・前残業／後残業がTRUEの場合、該当時刻が黄色マーカー＋※で表示される
  ・役割は「役席」「GL」「OP」のいずれか

  【役割ごとの配置先】
  まず夜勤かどうかで振り分け（夜勤＝開始22:00より遅い、または終了26:00より遅い）。

  ＜日勤＞
    OP     … 座席グリッド（全15席）に自動配置
    役席/GL … 早番／遅番エリア（各2行×3列＝最大6名）へ、
              役席→GLの順・出勤が早い順に配置
              （遅番＝開始12:00以降、または前残業TRUEかつ開始10:00以降）
              7人目以降は配置されずメッセージで通知

  ＜夜勤＞
    OP     … 夜勤用の座席グリッド（同じ15席レイアウト）に自動配置
    役席/GL … 1名なら「夜勤GL」枠2行1列目に配置
              2名以上なら1名を夜勤GL枠2行1列目
              （secret.csvで「夜勤GL席」指定者を優先、複数/該当なしはランダム）、
              次の1名を座席10、3人目以降は空席へ配置
    ※夜勤の座席探索では、同列で隣接する座席を候補があれば避ける
      （席固定等の都合で結果的に隣接する場合は問題としない）


■ rookie.csv（新人リスト。ヘッダー行あり。対象はOPのみ）
  列: 氏名, 新人度合い

  例:
    山田太郎,1

  数値が小さいほど新人。同数値の場合は月間シフトCSV内でその日の
  後ろの行にある人がより新人として扱われる。


■ secret.csv（配慮リスト＝個人情報を含むため取り扱い注意。ヘッダー行あり）
  列: 種別, 対象1, 対象2, 対象座席

  例:
    隣接禁止,山田太郎,佐藤花子,
    禁止席,鈴木一郎,,5
    席固定,高橋次郎,,7 11
    席固定,近藤　美穂,,夜勤GL席

  ・隣接禁止   … 対象1と対象2を同列の隣接座席に配置しない
  ・禁止席     … 対象1を、対象座席で指定した座席番号に配置しない
  ・席固定     … 対象1を、対象座席で指定した座席番号に必ず配置
                （他の全ルールより最優先。複数指定時はそのいずれか）
  ・対象座席は半角数字。複数指定はスペース区切り（半角・全角どちらも可）
  ・「禁止席」「席固定」は同一人物を2行以上に分けて記載不可
    （1人1行にまとめ、複数座席はスペース区切りで指定）
  ・席固定の対象座席には座席番号のほか特別な値「夜勤GL席」も指定可
    （夜勤の役席・GLが2名以上いる日、「夜勤GL」枠へ優先的に入れたい人を指定。
    　禁止席には指定不可。数字と併記も可＝例「夜勤GL席 3」）
    複数人が指定している場合は該当者の中からランダムに1名選出。
    選ばれなかった人は座席1〜15に配置され「夜勤GL席」バッジが付く。

  座席番号（全15席。右下の1席は存在しない）:
    1  5  9  13
    2  6 10  14
    3  7 11  15
    4  8 12  −


配置優先順位（共通ルール）
--------------------------------------------------------------------
席固定（secret.csv）＞ 新人固定席（rookie.csv）＞ 出勤時刻順

夜勤の座席探索に限り、同列で隣接する座席を（他に候補がある限り）回避する
（ソフトルール。席固定などにより結果的に隣接する場合は許容しエラーとしない）。


座席カードのバッジ一覧
--------------------------------------------------------------------
  新人1〜新人4 : rookie.csv記載者の優先順位
  席固定       : secret.csvで座席指定されている対象者
                 （候補1〜2件は座席番号、3件以上は「複数有」と表示）
  禁止席       : secret.csvで配置禁止されている対象者（表示ルールは席固定と同じ）
  隣禁止       : 隣接禁止ルールの対象者。ペアごとにA/B/C…が付き、
                 自分の属する全ペア記号を表示（例: 2ペアなら「AB」、
                 4ペア以上は「4以上」と表示）
  夜勤GL席     : secret.csvで「夜勤GL席」指定だが夜勤GL枠に選ばれず
                 座席1〜15に配置された対象者（夜勤グリッドのみ）


操作方法
--------------------------------------------------------------------
・座席カード／早番・遅番エリアのカードはドラッグ&ドロップで自由に移動可能
  （同じ枠内、早番⇔遅番、座席⇔あふれなど、枠をまたいだ移動も可）
・各カードの✎アイコンから氏名・時刻の手入力修正、当日の配置からの削除が可能
・ドラッグ操作は配置ルールを自動チェックしないため、手動変更後は
  「手動変更後 配置違反チェック」ボタンで確認する
  （日勤・夜勤の入れ違いや、夜勤GL枠が空のまま等も検出）


印刷
--------------------------------------------------------------------
「印刷用ページを開く」ボタンから、1ページ目＝日勤、2ページ目＝夜勤の
A4各1枚の印刷用ページを新しいタブで開く（両面コピー想定）。


配置の保存・読み込み
--------------------------------------------------------------------
・「現在の配置を保存」… 表示中の配置（手動調整分を含む）をJSONファイルとして
  ダウンロード
・「保存した配置を読み込む」… ダウンロード済みJSONファイルを選択すると、
  保存時点の配置画面を復元
・保存ファイルには secret.csv 由来の情報（席固定・禁止席等のバッジ情報）は
  一切含まれない（ホワイトリスト方式でエクスポート）。読み込み後に
  配置違反チェックやバッジ表示を使うには別途 secret.csv の読み込みが必要
  （読み込み済みなら自動的に再適用される）


技術メモ（開発者向け）
--------------------------------------------------------------------
・素のJavaScript（フレームワーク不使用）。window.SeatTool 名前空間に
  csv / algorithm / ui の3モジュールをぶら下げる構成
    window.SeatTool.csv       … CSVパース・バリデーション（csv.js）
    window.SeatTool.algorithm … 座席自動配置ロジック（algorithm.js）
    ui.js は上記2つを利用して画面を構築（他モジュールからは参照されない）
・保存/読み込みには File System Access API を条件付きで使用
  （非対応ブラウザでは通常のダウンロード/ファイル選択にフォールバック）
・動作確認はブラウザのみで完結。サーバー・Node.js等は不要
